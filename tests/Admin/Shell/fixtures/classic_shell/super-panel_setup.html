فقط آدرس پنل و API Token لازم است. بعد از ذخیره، «تست اتصال» را بزنید.

آدرسی که پنل را در مرورگر با آن باز می‌کنید، با مسیر مخفی (web base path) اگر دارد؛ مثلاً https://panel.example.com:2053/secret/ . اگر پنل روی همین سرور است: http://127.0.0.1:2053/secret/
در پنل 3x-ui: Settings → Security → API Token. این توکن دسترسی کامل مدیر دارد؛ رمزنگاری‌شده ذخیره می‌شود و هرگز نمایش داده نمی‌شود.
پنل غیرفعال خرید جدید نمی‌پذیرد؛ سرویس‌های موجود کار می‌کنند.
تنظیمات پیشرفته
آدرس سرویس اشتراک پنل برای ساخت لینک اشتراک مشتری؛ مثلاً https://sub.example.com:2096
پروکسی PANEL_PROXY_* تنظیم‌شده در سرور برای این پنل استفاده شود.
برای پنلی با گواهی self-signed، به‌جای خاموش کردن بررسی گواهی، هش SHA-256 کلید عمومی آن را وارد کنید (راهنما در docs/fa/panel-connection.md). برای گواهی معتبر (مثلاً Let's Encrypt) خالی بگذارید.
«خودکار» با تست اتصال تشخیص می‌دهد پنل API جدید (توکن) دارد یا نسخه قدیمی (نام کاربری/رمز) است. فقط در صورت نیاز حالت را دستی انتخاب کنید.
فقط وقتی در لینک‌های کانفیگ ساخته‌شده قرار می‌گیرد که نه پنل و نه اینباند هاستی بدهند.
