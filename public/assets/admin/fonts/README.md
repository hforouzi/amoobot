# Vazirmatn

`Vazirmatn-wght.woff2` is a copy of `public/miniapp/fonts/Vazirmatn-wght.woff2` (Vazirmatn v33.003, the variable
font, weights 100–900; see that folder's README). Licensed under the SIL Open Font License 1.1 (`OFL.txt`).

Used by `public/assets/admin/admin.css` (both admin layouts), so the admin panel loads no font from a CDN. When
updating it, update both copies and bump the `?v=` in `admin.css`.
