# Vazirmatn

`Vazirmatn-wght.woff2` is `fonts/webfonts/Vazirmatn[wght].woff2` (the variable font, weights 100–900, Persian/Arabic
and Latin) from the Vazirmatn v33.003 release, https://github.com/rastikerdar/vazirmatn/releases/tag/v33.003, renamed
without brackets. Licensed under the SIL Open Font License 1.1 (`OFL.txt`).

Used by `public/miniapp/app.css` (the Mini App) and `templates/subscription/_layout.html.twig` (the subscription page),
served from this site only (CSP `font-src 'self'`). When updating it, bump the `?v=` in both and in
`templates/miniapp/entry.html.twig` (the preload).
